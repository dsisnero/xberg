# xberg

High-performance document intelligence library

Crystal bindings generated by [alef](https://github.com/kreuzberg-dev/alef).

## Installation

Add to your `shard.yml`:

```yaml
dependencies:
  xberg:
    github: xberg-io/xberg
```

Then:

```sh
shards install
```

## Usage

```crystal
require "xberg"
```

## Development

```sh
shards install
crystal spec
crystal tool format
```
